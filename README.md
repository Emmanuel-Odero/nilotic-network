# Nilotic Network

A C++-based blockchain platform with a hybrid Proof-of-Stake model, DAO governance, and API support for diverse use cases.

## Prerequisites
- C++17 compiler (e.g., GCC, Clang)
- OpenSSL
- Boost.Asio
- Crow (C++ microframework)
- CMake
